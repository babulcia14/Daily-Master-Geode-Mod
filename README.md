# Daily-Master-Geode-Mod
Geode Mod

# Daily Master 1.0.0
Daily Master automatically collects the **reward for the Daily Level** in Geometry Dash—provided that you have already completed the Daily Level yourself in the standard game mode with a 100% score. The mod triggers the existing "collect" button within the game interface and confirms the update to the reward's status.
